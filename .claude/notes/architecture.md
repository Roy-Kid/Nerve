# Architecture

Plugins collect session, host PID and terminal slot, then forward raw Codex, Claude and Grok events to their machine's `POST /v1/hook?producer=…`. They never build snapshots or keep task state.

The resident singleton hub binds `127.0.0.1:17890`. `nerve-hub ensure` reuses a compatible instance or starts one and waits for readiness; an unrelated listener or incompatible protocol is an error. Surface disconnects do not end the hub.

Hub owns event mapping, conversation replacement, subagent/background handling, deduplication, local PID reaping, display projection, order, summaries and notification decisions. Runtime jobs are memory-only. Generic producers retain snapshot/event ingest APIs.

Each remote machine has its own hub. Only local hub opens SSH LocalForward tunnels, invokes remote ensure, persists machine configuration and reconnects. Local-only full frames are aggregated by stable machine ID and producer/session identity; no transitive replication. Offline origins retain their last snapshot; remote PID decisions remain remote.

macOS, Windows, tmux, VS Code and Tether web replace protocol-v2 full frames and retain UI state. Notification commands target a single connection of a unique capable instance; surfaces execute OS notifications and report delivery. Polling/reconnect frames contain no historical notification commands.

Canonical protocol fixture: `fixtures/hub-frame.json`, generated by `cargo run -p nerve-hub --example export_frame`. Website fixture is generated by `--example export_website`. Surface tests invoke the hub's offline projection, never copied classifiers.
